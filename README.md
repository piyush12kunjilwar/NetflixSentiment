# 📺 Netflix Content Sentiment Analysis Dashboard

A powerful, AI-driven sentiment analysis platform that visualizes audience reactions to Netflix original content using social media data. Built with Streamlit, NLTK, and Anthropic's Claude API.

![Dashboard Preview](generated-icon.png)

## 🌟 Features

### Core Functionality
- **Advanced Sentiment Analysis**: Real-time processing of social media comments using NLTK's VADER sentiment analyzer
- **Interactive Visualizations**: Dynamic, multi-layered charts powered by Plotly
- **AI-Powered Insights**: Content marketing recommendations generated by Claude AI
- **Demographic Filtering**: Filter data by age groups, regions, and genres
- **Dark Theme UI**: Netflix-inspired dark mode interface with smooth animations

### Visualizations
- Sentiment trends over time (stacked area chart)
- Show-wise sentiment distribution (stacked bar chart)
- Demographic insights (grouped bar chart)
- Regional distribution (interactive donut chart)

### AI Features
- Content marketing strategy recommendations
- Emotion-based show suggestions
- Trend analysis and actionable insights

## 🚀 Getting Started

### Prerequisites
- Python 3.11+
- Anthropic API key (for AI-powered insights)

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd netflix-sentiment-dashboard
```

2. Install dependencies:
```bash
pip install streamlit nltk plotly pandas anthropic
```

3. Set up environment variables:
Create a `.env` file and add your Anthropic API key:
```
ANTHROPIC_API_KEY=your_api_key_here
```

4. Run the application:
```bash
streamlit run main.py
```

The dashboard will be available at `http://localhost:5000`
